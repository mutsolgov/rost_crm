## ⚡ Ключевые возможности системы

- **15 состояний и 29 переходов воронки workflow:** автоматизация всех 14 шагов ТЗ от поиска контактов до ведения занятий и контроля метрик. Обязательное комментирование при возвратах и отменах.
- **Оптимистическая блокировка CAS (Compare-And-Swap):** проверка `expected_revision` исключает перезапись чужих изменений. Защита ввода AC21 — введенный текст не стирается при сетевых сбоях.
- **Двухфазный импорт каталогов (XLSX, XLS, CSV):** 100% чистый парсер на стандартной библиотеке Python (`xml.sax`, `zipfile`, `csv`) без внешних уязвимых библиотек. Предпросмотр с журналом ошибок строк до коммита в БД.
- **Аналитический движок отчётов:** три режима (Срезовый/Snapshot на дату, Активности/Activity, Накопительный/Created). Экспорт в форматы XLSX, PDF, CSV без сторонних бинарных утилит. Защита от CSV-инъекций (CWE-1236).
- **Интеграционный шлюз LMS и Сайта:** приём вебхуков по схеме Envelope v1.0, дедупликация на уровне ограничения целостности БД `uq_inbox_dedup`, криптографические подписи HMAC-SHA256, отказоустойчивость при недоступности внешних серверов (500–504).
- **Инварианты ИБ (152-ФЗ / ФСТЭК №117):**
  - Zero-Oracle принцип: прямой запрос чужого ID возвращает `404 Not Found` (не раскрывать существование записи).
  - Хранение JWT токенов сессии *strictly in-memory* (запрет `localStorage`/`sessionStorage` против XSS).
  - Потоковый антивирусный шлюз ClamAV по сокету TCP 3310 до сохранения файла.
  - Лимит размера вложений 25 МБ, белый список из 10 расширений ТЗ с проверкой заголовков (Magic Bytes).
- **Дизайн-система Ростелеком Gen2:** высокая контрастность (> 10:1), эргономика, адаптивность и отзывчивый интерфейс без перезагрузки страниц (SPA).

## 🚀 Быстрый запуск в Docker Compose (Production-Ready)

### 1. Подготовка окружения
```bash
# Клонирование репозитория
git clone <URL_РЕПОЗИТОРИЯ> rost_crm
cd rost_crm

# Создание конфигурационного файла
cp .env.example .env
```

### 2. Сборка и запуск стека
```bash
# Проверка синтаксиса и запуск всех 6 сервисов
docker compose up --build -d --wait --wait-timeout 240
```

Стек автоматически поднимает:
- `frontend` (Nginx + React 19 SPA) на порту `3000` (http://localhost:3000);
- `api` (FastAPI / Python 3.14) на порту `8000` (http://localhost:3000/docs);
- `keycloak` (OIDC IdP сервер) на порту `8080` (http://localhost:8080);
- `postgres` (PostgreSQL 16) во внутренней сети `backend_net`;
- `clamav` (потоковый антивирус daemon);
- `redis` (кэширование и rate limiting).

### 3. Сидирование демонстрационных данных
```bash
docker compose exec api python -m app.seed --seed-demo
```
