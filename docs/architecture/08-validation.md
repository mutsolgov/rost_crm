## Что не подтверждено этой работой

- PostgreSQL-миграции целевой схемы, executable OpenAPI/ports, фоновые handlers и новые бизнес-функции ещё предстоит написать по roadmap.
- Runtime backend-тесты, Docker/OIDC end-to-end, реальные API LMS/Laravel, файлы будущих renderer и scanner этой проектной работой не проверяются.
- GUI-импорт/визуальная проверка Archi не выполнялись; XML проходит структуру XSD, проверку импорта/расположения нужно завершить перед сдачей архитектурного артефакта.
- 50 пользователей, 10 concurrent reports, отклик ≤1 секунды, RPO/RTO и нормативное соответствие требуют отдельных испытаний/решений в целевой среде.
- Формулы метрик, окончательные внешние API, лимиты и retention остаются открытыми пунктами 06. Описанные рабочие правила позволяют начать независимую разработку, но не заменяют приёмку заказчика.

Полнота архитектурного покрытия означает наличие решения и пути проверки для каждого требования. Она не означает статус «реализовано» или «принято».
